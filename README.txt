FEDERAL MOTION — WEB TEST BUILD

Open index.html in a browser to test locally.

For phone testing, upload the contents of this folder to any static web host such as GitHub Pages, Netlify, or Cloudflare Pages.

Save data uses browser localStorage, so each device/browser keeps its own save.

This web conversion keeps the current desktop game's core systems: day/time cycle, map travel, moves, heat, health, trap/stash, drugs, suppliers, black market, crew, combat, hospital/death penalties, upgrades, market changes, and overnight events.
